# Caalin Tracker

Android app that sends mobile money by USSD from a list of money types (EVC Plus, eDahab, …),
locks with your fingerprint, types your saved PIN automatically, and saves every transaction.

Every push to `main` builds the APK on GitHub Actions. The signed APK lands on the `apk` branch
as `CaalinTracker.apk`; the build output is on the `build-log` branch.
